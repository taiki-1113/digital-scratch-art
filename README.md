# こすってアート

タブレットとタッチペン向けの、作品をこすって楽しむデジタルスクラッチアートです。サーバーアカウントやクラウド同期は使いません。作品一覧は合計13点（オリジナル3点、指定素材10点）です。指定素材は色画像として原寸の構図を保ち、線画ガイドをブラウザー内で生成します。

## 起動方法

Node.js 18以降を用意し、プロジェクトフォルダーで次を実行します。

```sh
node server.mjs
```

PCでは `http://localhost:8000` を開きます。タブレットから使う場合は、PCとタブレットを同じWi-Fiにつなぎ、PCのIPv4アドレスを使って `http://<PCのIPv4アドレス>:8000` を開きます（例: `http://192.168.3.13:8000`）。`192.168.3.1` は通常ルーターのアドレスです。初回接続時にWindowsファイアウォールが確認を表示したら、プライベートネットワークでのアクセスを許可してください。PWAインストールとオフライン利用には、HTTPSまたはlocalhostで開いてください。作品を一度開くとアプリ本体とサンプル作品がキャッシュされ、以後オフラインでも利用できます。保存データはブラウザーのローカルストレージ内にあります。

## GitHub Pagesで公開

`.github/workflows/pages.yml`を追加済みです。GitHubにリポジトリを作成してこのプロジェクトをpushし、リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選ぶと、`main`へのpushごとに自動公開します。公開先はActionsの実行結果に表示されます。静的ファイルだけで動くためNodeサーバーは不要です。

**GitHub Pagesのサイトはインターネット上で公開されます。リポジトリを非公開にしてもサイト自体は公開扱いです。** 今回の指定画像を公開サイトに載せると、画像もURLから閲覧できます。公開に使う前に、画像を公開してよいか確認してください。公開を避ける場合は、素材を含めずローカルLANだけで利用してください。

## 操作

- 作品一覧から絵を選んで開きます。
- ペンまたはマウスでこすると、同じ場所を何度もなぞるほど色が見えてきます。
- 「作品一覧」で戻り、「はじめから」で現在の作品だけを初期状態に戻します。
- 「細・中・太」でブラシの太さを切り替えます。削り速度を従来より抑え、削りカスの粒子を表示します。

## 作品の追加

`assets/`にカラー画像と（あれば）白い線画SVGを追加し、`app.js`先頭の`ART`配列に作品情報を登録します。線画がない作品では元画像からガイド線を生成します。オフラインでも新作を使うには、`sw.js`のプリキャッシュ対象にも素材ファイルを追加してください。保存形式はバージョン番号付きで作品ごとに管理されます。

## 素材と権利

オリジナル作品のほか、指定素材フォルダーには第三者のキャラクター・作品を含む画像があります。GitHub Pagesを有効にするとサイトと画像が公開されるので、個人利用として手元に留める場合は指定素材をアップロードしないでください。公開や配布をする場合は、素材ごとの権利と配布条件を確認してください。
